Static Tango

Poster Series


A series of experimental posters exploring the dynamization of typography and dealing with themes of grids, transformation and typographic systems with the use of code as well as analogue methods.
The poster is an animated homage to Hansje van Halem, created in Processing. It works with a grid of tangent functions and the displacement thereof to display the type.
Tools:
Processing
This poster works with 3D CSS transformations and the Dismal font. The rotation of the columns made out of letters creates the illusion of vertical movement.
Tools:
HTML, CSS
This poster is an interactive and generative nod to Steve McCaffery, built in p5.js and using webcam input with a playful ASCII-based output which utilizes the Dismal font.

Tools:
p5.js, JavaScript
This poster shows digitally photographed results of analogue typographic experiments with a glass bottle used as a disfiguring filter.
Tools:
Adobe Photoshop, digital camera
This poster uses a rectangular grid to display five lines of text. It is animated using periodic gradient animations showing and hiding the text.
Tools:
HTML, CSS
This poster is audio-reactive and is based on the variable font SplitFlap where the flaps react to the audio-input. A grid of G's performs the resulting vertical wave-like motion.
Tools:
HTML, CSS
