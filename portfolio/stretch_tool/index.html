Stretch Tool

Type Tool


Helvetica was re-drawn using DrawBot. After that, it was turned into a sandbox variable font where the horizontal lines of all all the non-round letters are stretched horizontally. The simple design tool lets the user play with the stretch as well as add perspective lines.
Tools:
Drawbot, Python
