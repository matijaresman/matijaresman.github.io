Perwolf

Type Tool


A web-based type tool that applies Perlin noise, a type of gradient noise used in computer graphics to generate natural-looking patterns, to the outlines of characters from any imported font.

Based on user-defined parameters for noise intensity and scale, the tool distorts the letterforms and generates a downloadable SVG graphic.
