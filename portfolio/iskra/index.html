Iskra Tool

Generative Design Tool


A web-based generative typographic tool developed for Iskra, an (as yet unopened) concert venue in Zagreb.

The p5.js tool works with a modular grid system in which a pixel-based typeface (using modular stars as pixels) is rendered and animated.

The concept was developed by, and the tool was created for, the Zagreb-based design-research studio DISKO.
Tools:
p5.js, JavaScript, HTML, CSS
